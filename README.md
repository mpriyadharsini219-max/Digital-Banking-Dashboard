# Digital Banking Dashboard

A responsive Digital Banking Dashboard built using HTML, CSS, and JavaScript.

## Features

- Account balance overview
- Income and expense summary
- Recent transactions
- Transaction status
- Quick banking actions
- Responsive design
- Interactive buttons

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

digital-banking-dashboard/
│
├── index.html
├── style.css
├── script.js
└── README.md

## How to Run

1. Clone or download the repository.
2. Open `index.html` in a web browser.
3. Explore the banking dashboard.
